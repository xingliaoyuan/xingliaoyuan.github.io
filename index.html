About Me

关于我

我叫天宇，2026 年入学，现在在沈阳理工大学读车辆工程，大一。 报这个专业的原因挺简单：从小就对车感兴趣，路上见到不认识的车型会忍不住去查一查它是什么车、多少钱、什么动力。

上了大学之后，除了专业课，我还想弄明白一件事——现在的车为什么越来越像一台电脑。 所以这学期我给自己加了一门“课外必修”：学编程。从 C 语言开始，现在也刚开始碰一点 C++。 目前还处在最基础的阶段，写得出能跑的小程序，但离“会写代码”还差得远，经常被一个报错卡半天。

我没打算把话说得太满。接下来的计划很朴素：把编程基础一点点补上，把专业课认真学好， 有空就多看看智能汽车和新能源汽车方面的东西，等基础够了，再试试把这两个方向凑到一起做点小东西。

我感兴趣的方向

🚗

汽车

路上看到不认识的车型会去查，喜欢看评测和车型对比，也爱琢磨这车为什么这么设计、值不值这个价。

⌨️

编程

刚开始学。最上头的时候是程序第一次按我想的那样跑起来，最崩溃的时候是编译报错看不懂。

智能汽车

对辅助驾驶、车机系统、车上那套软件是怎么运行的挺好奇，也是我想学编程的重要原因之一。

🔋

新能源汽车

电池、电机、电控这些和传统燃油车完全不同的东西，正是我们这届学生要面对的新内容。

🧩

搞懂原理

比起记住结论，我更想弄明白它是怎么运作的。齿轮怎么传动、悬架为什么这么布置，看懂一次就忘不掉。

📚

慢慢积累

现在水平一般，但每天都在往前走一点。目标不大：这学期先把编程基础写熟，专业课不挂科。

开始学 C 语言

因为想弄明白车上的软件到底是怎么写的，就从 C 语言开始。第一行 Hello World 折腾了半天， 后来又被分号、数组越界和指针轮流教做人。

最近

C 语言刚上手，又试着碰了一点 C++

现在的情况是：简单的程序能自己写出来，遇到复杂一点的逻辑还是得慢慢想。 C++ 只能算“见过面”，远谈不上会。计划是先别贪多，把 C 的基础写熟。

现在

跟着课程走，同时自己补编程

专业课上认真听，课外每天留一点时间写代码。智能汽车、新能源汽车这些方向的东西， 目前主要是看和记，等基础好一些再动手试。

以后

想试试把车和代码放在一起

还没想好具体做哪个方向，也不着急定。先把编程和车辆工程的专业知识都学扎实， 以后再找机会做点和汽车、和代码都相关的东西。
